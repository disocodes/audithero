# Security

- Employment Hero credentials belong in Databricks Secrets, never Git.
- Treat payroll and timesheet records as sensitive personal information.
- Use Unity Catalog least-privilege grants.
- Separate developer permissions from payroll dashboard-consumer permissions.
- Use a service principal for production bundle deployment where possible.
- Do not place production payroll extracts in test fixtures.
- Review AI/BI sharing before publication.
- Apply organisational retention, payroll-record and privacy requirements to Delta tables and exports.
