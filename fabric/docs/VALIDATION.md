# Production validation checklist

Before using AuditHero for remediation or payroll sign-off:

- [ ] Effective industrial instrument is known for audited employees.
- [ ] Historical employment type is populated.
- [ ] Historical SCHADS classification mapping is independently checked.
- [ ] Employment Hero pay categories are mapped explicitly.
- [ ] Work locations have state and local-holiday keys where needed.
- [ ] Representative full-time rosters are available for overtime testing.
- [ ] Part-time written patterns/variations are loaded where relevant.
- [ ] Sleepover and broken-shift examples reconcile manually.
- [ ] Weekly/fortnightly overtime examples reconcile manually.
- [ ] Public-holiday examples reconcile manually.
- [ ] TOIL/meal/rest controls are reviewed where used.
- [ ] Direct Lake remediation measures exclude unresolved review cases.
- [ ] A payroll/IR reviewer signs off the configured interpretation.

A successful notebook run means the software executed; it is not itself legal validation of Award coverage or historical source facts.
