# AuditHero on Databricks

Databricks is a complete deployment target using:

- Unity Catalog / Delta
- Databricks Secrets
- notebooks and the shared AuditHero wheel/package
- Lakeflow Jobs / Declarative Automation Bundle
- Databricks AI/BI dashboard
- runtime self-tests and readiness analysis

The shared SCHADS engine now also includes the deeper compliance controls used by Fabric: part-time written patterns, rest-after-overtime, meal-break evidence, remote-work aggregation, TOIL and industrial-instrument history.

See the repository root `README.md`, `QUICKSTART.md` and `docs/` for operating runbooks.
