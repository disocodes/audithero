# Complete Databricks workflow

1. Deploy bundle.
2. Run setup and Databricks-native self-test.
3. Configure Employment Hero secrets.
4. Run connection test.
5. Run readiness analysis.
6. Populate tenant mappings and compliance control registers.
7. Validate a known pay period.
8. Run historical audit.
9. Review AI/BI dashboard.
10. Enable monthly job after validation.

The Databricks runtime must apply the same shared modules as Fabric before reconciliation: broken shifts, sleepover grouping, roster/daily/period overtime, part-time patterns, meal breaks, rest after overtime, industrial-instrument history, supplemental events/remote-work aggregation and TOIL.
